# Savory Stories Site

Create a premium, modern, fully responsive multi-page restaurant website using React + TypeScript + Tailwind CSS.

The website should feel like a real high-end restaurant website, not a basic template. Use clean typography, elegant spacing, high-quality food/restaurant imagery, smooth animations, subtle hover effects, and a professional luxury visual style.

IMPORTANT: MULTI-PAGE REQUIREMENT

Build this as a true multi-page React website using React Router.

Do NOT create one single long scrolling page containing all sections.

Create separate routes/pages:

/ → Home

/about → About

/menu → Menu

/experience → Experience

/gallery → Gallery

/reservations → Reservations

/contact → Contact

Every page must have its own layout and content while sharing the same Header and Footer.

Navigation must work correctly between all pages without page errors.
